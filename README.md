# DRIPS

**Domain Randomisation for Image-based Perivascular Spaces Segmentation**

DRIPS is a deep-learning framework for automated segmentation of perivascular spaces (PVS) on structural MRI. It was trained with domain randomisation on synthetic data and supports T1w, T2w, FLAIR, isotropic, and anisotropic scans.

DRIPS is distributed as an **Apptainer/SIF container**. Docker is no longer supported.

## Requirements

- Apptainer or Singularity
- NVIDIA GPU and compatible driver recommended
- Input image in NIfTI format (`.nii` or `.nii.gz`)

## Download

Download the current `drips_blackwell.sif` file from Google Drive: https://drive.google.com/file/d/1Oa08T3h6fMeLlc5omLL00sj8UU2mlnYc/view?usp=sharing .

## Run DRIPS

Place your input image in a local directory, for example:

```text
cases/
└── t1w.nii.gz
```

Run the container with GPU support:

```bash
apptainer run --nv \
  --bind "$HOME/cases:/data" \
  drips_blackwell.sif \
  --in /data/t1w.nii.gz \
  --out /data/pvs.nii.gz \
  --posterior /data/pvs_probability.nii.gz \
  --model auto \
  --pvs-contrast hypointense
```

This command creates:

```text
cases/
├── pvs.nii.gz
└── pvs_probability.nii.gz
```

`pvs.nii.gz` is the binary PVS segmentation and `pvs_probability.nii.gz` is the posterior probability map.

## ICV mask and SIAM

If no ICV mask is supplied, DRIPS invokes the included `siam-pred` command to generate a native-space ICV mask and exclude SIAM-labelled CSF/ventricular CSF regions. **We highly recommend this option.**

To retain the generated mask:

```bash
apptainer run --nv \
  --bind "$HOME/cases:/data" \
  drips_blackwell.sif \
  --in /data/t1w.nii.gz \
  --out /data/pvs.nii.gz \
  --posterior /data/pvs_probability.nii.gz \
  --save-icv /data/icv_siam.nii.gz \
  --model auto \
  --pvs-contrast hypointense
```

Alternatively, provide an existing native-space ICV mask:

```bash
apptainer run --nv \
  --bind "$HOME/cases:/data" \
  drips_blackwell.sif \
  --in /data/t1w.nii.gz \
  --icv-mask /data/icv_mask.nii.gz \
  --out /data/pvs.nii.gz \
  --posterior /data/pvs_probability.nii.gz \
  --model auto \
  --pvs-contrast hypointense
```

## Key options

| Option | Description |
|---|---|
| `--in` | Input 3D NIfTI image |
| `--out` | Output binary PVS segmentation |
| `--posterior` | Output PVS probability map |
| `--icv-mask` | Optional native-space ICV mask; skips  |
| `--save-icv` | Save the ICV mask generated by  |
| `--model 3d` | Force the 3D model |
| `--model 2d` | Force the 2D model |
| `--pvs-contrast hyperintense` | Use when PVS are bright, typically T2w |
| `--pvs-contrast hypointense` | Use when PVS are dark, typically T1w |
| `--threshold` | Binary segmentation threshold; default: `0.5` |
| `--device auto` | Automatically use CUDA when available |
| `--threads` | Number of  preprocessing threads; default: `4` |

## GPU check

Before first inference on a new system, verify that the container can access the GPU:

```bash
apptainer exec --nv drips_blackwell.sif python3 - <<'PY'
import torch
print(torch.__version__)
print(torch.version.cuda)
print(torch.cuda.get_arch_list())
assert torch.cuda.is_available()
print(torch.randn(8, 8, device="cuda").sum())
PY
```
